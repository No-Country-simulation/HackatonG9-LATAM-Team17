## MODIFIED Requirements

### Requirement: Consolidación de Historial
El sistema DEBE reflejar en el historial del usuario las transacciones independientes agregadas recientemente.

#### Scenario: Visualización combinada
- **WHEN** el usuario navega a la pestaña de Historial
- **THEN** observa un registro que incluye las transacciones individuales añadidas desde el Dashboard junto a los análisis financieros generados.
